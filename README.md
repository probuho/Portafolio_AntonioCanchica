## 📖 Descripción

Portafolio personal de **Antonio José Ruiz Canchica** - Junior Full Stack Developer. Un sitio web moderno con diseño cyberpunk inspirado en Blade Runner, Matrix y Cyberpunk 2077, que refleja mi pasión por la ciencia ficción y la cultura geek.

### ✨ Características

- 🎨 **Diseño Cyberpunk Moderno**: Inspirado en películas de ciencia ficción con efectos de neón, glassmorfismo y animaciones suaves
- 🔗 **Integración con GitHub**: Muestra automáticamente mis proyectos más recientes usando la API de GitHub
- 📱 **Totalmente Responsivo**: Optimizado para todos los dispositivos
- ⚡ **Rendimiento Optimizado**: Construido con Next.js 15 y React 19
- 🎯 **SEO Optimizado**: Metadata completa para mejor visibilidad
- 💼 **CV Interactivo**: Visualización y descarga de mi currículum
- 📧 **Formulario de Contacto**: Integración directa con email

## 🛠️ Tecnologías Utilizadas

- **Frontend**: React 19, TypeScript, Next.js 15
- **Estilos**: Tailwind CSS, CSS Modules
- **Animaciones**: Framer Motion, CSS Animations
- **Iconos**: React Icons
- **Hosting**: Vercel (recomendado)

## 🚀 Instalación y Uso

### Prerrequisitos

- Node.js 18+ instalado
- npm o yarn

### Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/probuho/Portafolio_AntonioCanchica.git
cd Portafolio_AntonioCanchica
```

2. Instala las dependencias:
```bash
npm install
```

3. Ejecuta el servidor de desarrollo:
```bash
npm run dev
```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador

### Scripts Disponibles

```bash
npm run dev      # Inicia el servidor de desarrollo con Turbopack
npm run build    # Construye la aplicación para producción
npm start        # Inicia el servidor de producción
npm run lint     # Ejecuta el linter
```

## 📦 Deployment en Vercel

### Opción 1: Usando Vercel CLI

1. Instala Vercel CLI:
```bash
npm i -g vercel
```

2. Despliega:
```bash
vercel
```

### Opción 2: Usando GitHub

1. Conecta tu repositorio con Vercel
2. Vercel detectará automáticamente Next.js
3. ¡Deploy automático en cada push!
